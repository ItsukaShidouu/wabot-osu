# wabot-osu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bot WhatsApp komunitas osu! dengan verifikasi member via osu! API, auto-kick timeout, dan warn+kick untuk link terlarang.

**Architecture:** Baileys untuk koneksi WA, SQLite via better-sqlite3 untuk state, axios untuk osu! API OAuth client credentials. Handler terpisah untuk event grup (join/leave) dan pesan (verif reply, link filter, admin command).

**Tech Stack:** Node.js 20+, TypeScript, baileys ^7, better-sqlite3, axios, dotenv

**Spec:** `docs/superpowers/specs/2026-11-05-wabot-osu-design.md`

## Global Constraints

- TypeScript strict mode aktif
- Semua file di `src/`, kompilasi output ke `dist/`
- Env vars wajib ada saat boot — crash early jika tidak ada
- `VERIFY_TIMEOUT_MS=300000` (5 menit), `MAX_WARNS=3`
- osu! API base URL: `https://osu.ppy.sh/api/v2`
- JID format WA: `628xxx@s.whatsapp.net` (user), `628xxx-ts@g.us` (grup)
- Baileys session disimpan di `data/auth/`
- SQLite file: `data/bot.db`

## Review Focus

- Member kirim username osu! tidak valid (typo/akun dihapus) → bot reply error, timer tetap jalan
- Member kirim pesan di grup lain saat pending verif di grup berbeda → hanya verif di grup yang pending
- Domain blacklist match subdomain (`evil.com` harus block `sub.evil.com`)
- Race condition: member di-kick admin manual sebelum timeout verif selesai → timer cleanup tidak error
- Warn count persist jika member keluar lalu masuk lagi → warn tidak direset otomatis

- [ ] **Step 3: Implement `isBlacklistedLink(text, blacklist): boolean`**

Extract semua URL dari `text` via regex `/(https?:\/\/[^\s]+)/g`. Parse hostname tiap URL. Untuk setiap domain di blacklist, cek `hostname === domain || hostname.endsWith('.' + domain)`. Return `true` jika ada match.

- [ ] **Step 4: Implement `handleMessage(msg, sock, kickFn)`**

Flow (urutan cek):
1. Skip jika bukan pesan grup atau bukan dari user (bot message / system)
2. Ambil `senderJid`, `groupJid`, `text` dari msg
3. **Admin command**: jika `senderJid === config.BOT_ADMIN_JID`:
   - `!addomain <domain>` → `db.addDomain(domain)`, reply konfirmasi
   - `!rmdomain <domain>` → `db.removeDomain(domain)`, reply konfirmasi
   - `!resetwarn <nomor>` → `db.resetWarns(nomor@s.whatsapp.net, groupJid)`, reply konfirmasi
4. **Verif reply**: jika `pendingMap.has(senderJid)` dan pesan bukan command:
   - Treat seluruh text sebagai username osu!
   - `attemptVerify(senderJid, text.trim())`
   - Sukses → reply "✅ Verifikasi berhasil! Selamat datang, {username}!"
   - Gagal → reply "❌ Username osu! tidak ditemukan. Coba lagi."
5. **Link filter**: jika user sudah terverif (`db.isVerified(senderJid)`):
   - `isBlacklistedLink(text, db.getBlacklist())`
   - Jika iya → `db.incrementWarn(senderJid, groupJid)`, kirim pesan warn ke grup
   - Jika warn count >= `config.MAX_WARNS` → `kickFn(groupJid, senderJid)`

- [ ] **Step 1: Implement `src/index.ts`**

```ts
import makeWASocket, { useMultiFileAuthState, DisconnectReason } from 'baileys'
import { Boom } from '@hapi/boom'
import { initDb } from './services/db.js'
import { handleGroupUpdate } from './handlers/group.js'
import { handleMessage } from './handlers/message.js'
import { config } from './config.js'

async function start() {
  initDb()
  const { state, saveCreds } = await useMultiFileAuthState('data/auth')
  const sock = makeWASocket({ auth: state, printQRInTerminal: true })

  const kickFn = async (groupJid: string, userJid: string) => {
    try {
      await sock.groupParticipantsUpdate(groupJid, [userJid], 'remove')
    } catch (e) {
      console.error('kick failed', e)
    }
  }

  sock.ev.on('creds.update', saveCreds)

  sock.ev.on('connection.update', ({ connection, lastDisconnect }) => {
    if (connection === 'close') {
      const shouldReconnect = (lastDisconnect?.error as Boom)?.output?.statusCode !== DisconnectReason.loggedOut
      if (shouldReconnect) start()
    }
  })

  sock.ev.on('group-participants.update', (update) =>
    handleGroupUpdate(update, sock, kickFn)
  )

  sock.ev.on('messages.upsert', ({ messages }) => {
    for (const msg of messages) handleMessage(msg, sock, kickFn)
  })
}

start()
```
